# Final Polish Plan

## 목표

현재 완성된 원버튼 리듬 코어를 유지하면서 다음 세 가지를 제출 버전의 핵심 완성 요소로 추가한다.

1. 읽기 쉽고 게임의 분위기와 맞는 UI
2. 숨겨진 무적 치트를 정식 기능으로 만든 연습 모드
3. 콤보가 높아질수록 화면과 캐릭터가 미쳐가는 광란 연출

방향키 판정 확장은 진행하지 않는다. 최종 조작은 `Space` 또는 마우스 왼쪽 클릭을 사용하는 원버튼 방식이다.

## Phase 1 — 정식 연습 모드

현재 구현된 `invincible` 기능을 숨겨진 치트가 아니라 타이틀에서 선택할 수 있는 정식 모드로 승격한다.

- [ ] 타이틀에 `일반 모드`와 `연습 모드` 선택 버튼 추가
- [ ] 연습 모드에서는 Miss가 발생해도 체력이 감소하지 않음
- [ ] 콤보, 점수, 판정, 음악 진행은 일반 모드와 동일하게 유지
- [ ] HUD에 `PRACTICE` 배지 표시
- [ ] 결과 화면에 연습 모드 기록임을 표시
- [ ] 기존 `₩` 무적 토글을 제출 빌드에서 제거하거나 개발 빌드로 제한

완료 조건:

- 타이틀에서 두 모드를 명확하게 선택할 수 있다.
- 연습 모드로 곡을 끝까지 플레이할 수 있다.
- 플레이 중 현재 모드를 항상 확인할 수 있다.
- 연습 모드가 일반 모드의 판정 로직을 별도로 복제하지 않는다.

## Phase 2 — UI 개선

정보의 중요도는 `판정 → 콤보 → 체력 → 남은 시간 → 점수` 순서로 둔다.

- [ ] HP 숫자를 불꽃 아이콘 5개로 교체하거나 아이콘을 병행
- [ ] 콤보를 더 크고 중앙에 가깝게 배치
- [ ] 남은 시간과 점수의 시각적 비중 축소
- [ ] 일반/연습 모드 배지 추가
- [ ] 타이틀의 제목, 설명, 모드 버튼 사이 계층 정리
- [ ] 결과 화면의 승패, 점수, 최대 콤보, 재시작 안내 계층 정리
- [ ] Perfect / Good / Miss에 서로 다른 크기와 움직임 적용
- [ ] 1280×720 및 브라우저 리사이즈 상태에서 가독성 확인

완료 조건:

- 처음 실행한 사람이 설명 없이 모드를 선택하고 시작할 수 있다.
- 플레이 중 판정과 콤보가 가장 먼저 읽힌다.
- 광란 연출이 강해져도 체력과 남은 시간을 확인할 수 있다.

## Phase 3 — 콤보 광란 효과

광란은 무작위 효과가 아니라 콤보 단계에 따라 점진적으로 상승한다. 기존 불인간의 춤과 머리 크기 변화를 기준으로 배경, 조명, HUD 반응을 연결한다.

| 콤보 | 단계 | 핵심 연출 |
|---:|---|---|
| 0–9 | 정상 | 현재 기본 화면, 작은 불꽃과 약한 배경 |
| 10–29 | 점화 | 보라색 팔레트, 조명 확대, UI 박자 펄스 |
| 30–49 | 광란 | 독성 녹색 강조, 배경 나방 선명화, Perfect 화면 충격 |
| 50+ | 신격화 | 적색·황색 과열, 강한 배경 호흡, 판정·콤보 문구 변질 |

- [ ] `combo`에서 광란 단계를 한 곳에서 계산
- [ ] 불인간의 춤, 머리 크기, 조명 강도를 단계와 연결
- [ ] 배경 색상과 나방 관객의 투명도를 단계와 연결
- [ ] HUD 펄스 강도와 판정 문구를 단계와 연결
- [ ] Perfect 순간에만 짧은 화면 충격 적용
- [ ] Miss 시 광란 단계가 기본 상태로 빠르게 복귀
- [ ] 화면 흔들림, 플래시, 색상 변화가 판정 가독성을 가리지 않는지 확인

완료 조건:

- 콤보가 올라갈수록 화면이 명확하게 강해진다.
- 현재 광란 단계를 숫자 설명 없이도 체감할 수 있다.
- Miss 후 화면이 정상 단계로 돌아온다.
- 50+ 콤보에서도 접근 나방과 판정 지점을 읽을 수 있다.

## Phase 4 — 제출 준비

- [ ] Godot Standard(non-Mono) 버전과 Web export template 준비
- [ ] Web export 결과 파일명을 `index.html`로 설정
- [ ] FPS 오버레이와 개발 로그 제거 또는 비활성화
- [ ] 일반 모드 승리와 패배를 각각 재현
- [ ] 연습 모드로 곡을 끝까지 플레이
- [ ] 브라우저에서 오디오, 클릭, Space, 모드 선택, 재시작 확인
- [ ] 제출용 GIF 또는 스크린샷 제작
- [ ] 제출 페이지에 한 줄 설명과 조작법 작성

## 작업 순서

1. 연습 모드
2. UI 개선
3. 콤보 광란 효과
4. Web export와 QA
5. 캡처와 제출

## 범위 제한

최종 폴리싱 중에는 다음 기능을 추가하지 않는다.

- 방향키 판정
- 동시 입력과 복수 키 조합
- 새로운 노트 종류
- 새로운 이동 패턴
- 스테이지 선택
- 캐릭터 외형 바리에이션 추가
- 실제 3D 전환

## 바로 다음 행동

타이틀 화면에 `일반 모드`와 `연습 모드` 버튼을 만들고, 기존 `invincible` 상태를 선택한 모드에서 설정한다.
