# GDD

## 한 줄 설명
- 머리가 불인 픽토그램 인간이 중앙에서 춤을 추고, 빛에 홀린 나방인간들이 사방에서 나루토 러닝으로 달려오는 원버튼 타이밍 아케이드 게임.

## 확정 콘셉트

### 중앙 캐릭터

- 머리: 불
- 몸: 사람 픽토그램
- 행동: 중앙에서 계속 춤을 춘다.

### 접근 캐릭터

- 머리: 나방
- 몸: 사람 픽토그램
- 행동: 팔을 뒤로 뻗은 나루토 러닝 자세로 중앙의 불을 향해 달려온다.

### 판정 연출

- Perfect: 중앙 캐릭터가 강력하고 황당한 춤 포즈를 취하며 나방인간을 순식간에 완전히 태워버린다.
- Good: 나방인간이 불완전하게 타면서 화면 밖으로 도망간다.
- Miss: 나방인간이 중앙 캐릭터의 불 머리에 들러붙어 불꽃을 잠깐 약하게 만들고 콤보가 초기화된다.
- 콤보가 높아질수록 춤과 화면 연출이 점점 격렬해진다.
- 연소는 잔혹하게 표현하지 않는다. 검은 실루엣, 짧은 연기, 재가 떨어지는 픽토그램식 슬랩스틱으로 표현한다.

### 판정 범위 표현

- 개발 중인 색상 원은 디버그 표시로 유지하되 실제 게임에서는 기본적으로 숨긴다.
- 불대가리 아래의 바닥 조명으로 판정 범위를 표현한다.
- 넓고 흐린 네온 빛은 Good 범위, 작고 강한 라임·노란 빛은 Perfect 범위다.
- Miss 영역에는 별도의 빛을 표시하지 않는다.
- 조명은 실제 판정 거리와 정확히 일치해야 한다.
- 조명의 크기 변화는 판정 범위가 움직이는 것처럼 보이지 않도록 5~10% 이내로 제한한다.
- 필요하면 나방인간이 Good 범위에 들어올 때 윤곽을 밝히고, Perfect 범위에서는 전체를 짧게 번쩍여 가독성을 보조한다.

## 점수와 콤보

### 기본 규칙

- Perfect: 기본 5점, 콤보 +1
- Good: 기본 1점, 콤보 +1
- Miss 및 자동 Miss: 점수 없음, 콤보 0으로 초기화
- 성공해서 도달한 새 콤보 단계에 따라 해당 판정 점수에 배율을 적용한다.

| 콤보 | 점수 배율 |
|---:|---:|
| 0~9 | ×1 |
| 10~29 | ×2 |
| 30~49 | ×3 |
| 50+ | ×4 |

### 콤보와 불화력

- 콤보는 중앙 캐릭터의 불화력을 나타내는 연출 값이다.
- 콤보가 높아질수록 불 머리, 바닥 조명, 연소 연출, 춤의 강도가 커진다.
- 불화력은 시각적 progression이며 체력, 공격력, 데미지 시스템이 아니다.
- Miss가 발생하면 콤보와 불화력이 기본 단계로 돌아간다.

| 콤보 | 불화력 단계 | 연출 방향 |
|---:|---|---|
| 0~9 | 정상 | 작은 불꽃, 약한 바닥 빛 |
| 10~29 | 점화 | 보라색 팔레트, 조명 확대, UI 박자 펄스 |
| 30~49 | 광란 | 독성 녹색 강조, 배경 호흡, Perfect 화면 충격 |
| 50+ | 신격화 | 적색·황색 과열, 판정·콤보 문구 변질 |

### 코미디의 핵심

- 필사적으로 나루토 러닝을 하는 나방인간과 태연하게 춤추는 불대가리의 대비.
- 진지한 접근 동작과 황당한 판정 포즈의 대비.
    
## 핵심 재미

- 플레이어가 반복해서 즐길 행동: 중앙에 도달하는 오브젝트를 타이밍에 맞춰 클릭하고 콤보를 이어간다.
- 재미를 확인할 가장 작은 실험: 네 방향에서 일정 간격으로 오브젝트가 날아오고, 클릭 타이밍에 따라 Perfect / Good / Miss가 표시된다.
    
## 핵심 조작
- 이동: 없음
- 주요 행동: 마우스 클릭 또는 단일 키 입력
    
## 승리와 실패
- 승리: 음악을 반복하지 않고 90초를 버틴다.
- 실패: 체력이 0이 되면 불이 꺼진다.
- 일반 모드 Miss는 체력 감소와 콤보 초기화, 연습 모드 Miss는 콤보만 초기화한다.

## 현재 구현 상태 — v0.2.0, 2026-07-29

- 판정은 거리 기반 MVP에서 음악 재생 위치를 기준으로 한 시간 판정으로 발전했다.
- Perfect 허용 범위는 기본 `±0.07초`, Good 허용 범위는 기본 `±0.2초`다.
- Perfect는 5점, Good은 1점이며 성공 시 콤보가 증가한다.
- 나방을 놓치면 체력이 감소하고 콤보가 초기화된다.
- 기본 체력은 5이며, 음악을 반복하지 않고 90초를 버티면 승리하고 체력이 0이 되면 패배한다.
- 음악 구간에 따라 노트 밀도와 이동 시간이 변하며, 후반에는 사인파·궤도형 나방이 추가된다.
- v0.2 음악의 강약 구간에 맞춰 도입·상승·브레이크·최고조·냉각·재폭주로 밀도가 변한다.
- 마지막 12박은 새 나방을 생성하지 않고 음악과 화면만 남긴 뒤 종료한다.
- 개발용 기능으로 무적 토글과 판정 범위 표시를 제공한다.
- 손그림 타이틀, 연습 모드 체크박스, 불꽃 체력, 점수·콤보, 시간 바와 결과 화면으로 UI를 전면 개편했다.
- 실제 수치와 연출은 최종 플레이 테스트 결과에 따라 조정한다.

- 스테이지 선택
- 복잡한 노트 종류

- 다수의 캐릭터 종류
- 코어 검증 전 대량의 스프라이트 제작
- 체력, 공격력, 데미지 등 별도의 전투 시스템
- 사실적인 화염 시뮬레이션과 잔혹한 표현

## 보류 아이디어

### 2.5D 쿼터뷰

- 쿼터뷰 3D 공간에 `Sprite3D` Billboard 캐릭터를 배치한다.
- 불대가리 댄서는 중앙에서 춤추고, 나방인간은 사방에서 나루토 러닝으로 접근한다.
- Core MVP와 반복 플레이가 완성된 뒤에만 검토한다.
- 먼저 현재 2D 구조에서 대각선 경로, 원근에 따른 크기 변화, Y 정렬로 가짜 쿼터뷰를 시험한다.
- 실제 3D 전환은 별도 테스트 Scene에서 최대 1시간만 검증한다.
- 1시간 안에 기존 2D보다 명확하게 좋은 화면이 나오지 않으면 즉시 폐기한다.
- 이 아이디어 때문에 현재 `Node2D` 코어를 재작성하지 않는다.
